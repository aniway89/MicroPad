# Micro PAD — Retro PCB Design

A small macropad project designed using KiCad and FreeCAD. This repository contains the PCB design, schematic, 3D model, and related resources used to build the project.

## Project Files

- **PCB schematic/** — PCB schematic and related design files.
- **PCB schematic/FreeCAD Files/** — FreeCAD design files.
- **PCB schematic/PCB STEP file/** — STEP models related to the PCB.
- **Micro PAD free CAD IMAGES/** — Screenshots of the 3D model and CAD design.
- **Resources/** — Additional resources used in the project, including key, switch, and microcontroller 3D models.
- **Micro PAD OBJ.obj** — 3D model exported in OBJ format.
- **Micro PAD STEP.step** — 3D model exported in STEP format.

## Software Used

- KiCad — Schematic and PCB design.
- FreeCAD — 3D modelling and enclosure design.

## Resources

The `Resources` folder contains supporting models and files used during the design process, including:

- Key models
- Switch STEP files
- Seeed Studio XIAO SAMD21 3D model
- KiCad-related resources

These files are used to help position and check the components in the 3D design.


## Status

The project design stage is completed. PCB and enclosure designs are being developed and checked.
